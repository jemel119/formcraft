# CampusConnect Registration

CampusConnect is a four-step practice registration form for a student club platform.
Open `index.html` in a browser and use fictional data to complete Identity, Security, Profile, and Review.
The project uses Module 5 HTML constraints and the Module 8 JavaScript validation pattern for rules such as the campus email domain and password confirmation.
It applies Module 6 validation timing by checking fields on blur, rechecking flagged fields on input, and checking the entire form before Review and final submission.
It follows Module 9 by providing inline errors and a linked error summary.
I kept each step's inputs in the page so Back and Edit preserve entries, while a page refresh starts a new session.
Review displays non-secret entries and a “Password set” indicator.
This is a browser-only demo, so submitting confirms that validation passed without sending data to a server.
